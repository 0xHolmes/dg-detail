# NERO DETAILING — Demo concept

Fictional demo website (IT/EN). Not the website of any real business.

## Run
Open `index.html` in a browser, or serve the folder (`npx serve`).

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch `main` / root.
- **Vercel:** import the repo, framework preset *Other*, no build step.

## Customize
- Texts: Italian lives in `index.html`; English in the `E` object in `js/main.js`.
- Images: replace files in `images/` (same names).
- Sample photos may show third-party brand marks: replace with licensed images before real use.
